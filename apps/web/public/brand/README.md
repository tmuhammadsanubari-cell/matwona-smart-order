# Aset Brand

Letakkan file resmi dari mitra di sini:

- `matwona-logo.svg` — logo utama (putih/cream di atas hijau)
- `matwona-logo-green.svg` — logo hijau di atas latar terang
- `icon-192.png`, `icon-512.png` — ikon PWA (lalu isi `icons` di `public/manifest.webmanifest`)
- Font Mosvita (jika lisensi tersedia) → pindahkan ke `src/fonts/` dan pakai `next/font/local` di `layout.tsx`

Jangan membuat ulang logo dengan font Anton; selalu pakai SVG resmi.
